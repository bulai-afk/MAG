# Чат 06 — Проверяемые AI-комментарии

Ты работаешь только над этапом 6 MAG. Прочитай раздел AI-комментариев, безопасность и observability в `docs/PROJECT_PLAN.md`. Сначала проверь готовые KPI и `ChartDataset`.

## Входное условие

Отчёт детерминированно рассчитывает показатели и графики без участия AI.

## Цель

Добавить объяснения результатов простым языком, не позволяя модели придумывать цифры или выдавать гипотезы за причины.

## Выполни

1. Создай `AiProvider` interface и mock provider.
2. Реализуй адаптер выбранного российского провайдера.
3. Подготовь versioned prompts.
4. Передавай только необходимые агрегированные facts.
5. Запрашивай структурированный JSON: summary, wins, risks, hypotheses, nextActions и referencedFacts.
6. Валидируй JSON Schema/Zod.
7. Проверяй каждое число по исходным facts.
8. Реализуй bounded retry и deterministic fallback.
9. Добавь генерацию/перегенерацию отдельной секции.
10. Сохраняй generated и edited text отдельно.
11. Добавь обязательный review перед публикацией.
12. Измеряй latency, token usage и стоимость без утечки prompt/data.
13. Напиши unit, contract, integration и adversarial tests.

## Ограничения

- AI не рассчитывает KPI.
- Причинные утверждения без доказательств запрещены; только гипотезы.
- Исходный CSV и PII не отправляются модели.
- Недоступность AI не блокирует ручной отчёт.
- Не добавляй второй production provider до измеримой необходимости.

## Готово, когда

- все ответы проходят schema validation;
- числовые утверждения подтверждаются facts;
- ручная редактура сохраняется;
- fallback работает при outage;
- стоимость одного отчёта измеряется;
- чувствительные данные отсутствуют в логах.

В финале укажи provider/model, prompt version, guardrails, стоимость тестового отчёта и известные ограничения качества.
