## Общие правила

- Источник требований: [`docs/PROJECT_PLAN.md`](../PROJECT_PLAN.md).
- Перед изменениями проверить состояние Git и существующий код.
- Работать только в scope выбранного этапа.
- Не исправлять несвязанные проблемы и не переходить к следующему этапу.
- Не коммитить секреты, реальные персональные данные и production credentials.
- После существенных изменений запускать typecheck, lint и релевантные тесты.
- Обновлять документацию, если фактическая реализация меняет контракт.
- В конце сообщать изменённые файлы, результаты проверок, риски и оставшиеся задачи.
- Если входные условия этапа не выполнены, остановиться и назвать конкретный blocker.
