# Decision log — этап 0

Дата фиксации: 2026-09-09  
Источник, если не указано иное: интервью с владельцем продукта.

Статусы:

- `confirmed` — владелец явно выбрал для спецификации;
- `assumption` — вывод команды discovery, владелец не формулировал дословно;
- `to-validate` — проверить у пользователей или по реальным CSV.

Ответ владельца не равен подтверждённому спросу.

| ID | Решение | Источник | Статус | Условие пересмотра |
| --- | --- | --- | --- | --- |
| D-001 | Первый платящий пользователь MVP — фрилансер / соло-маркетолог, не владелец агентства | Интервью, смена сегмента после проверки доступа | `confirmed` | ≥3 агентства просят продукт раньше, чем фрилансеры, и готовы к beta |
| D-002 | Агентства 2–20 человек — следующий сегмент | Интервью | `confirmed` | После 10 интервью с фрилансерами боль не подтвердится |
| D-003 | Покупатель = пользователь = фрилансер | Интервью | `confirmed` | Появится сценарий, где платит студия/агентство за соло |
| D-004 | География: Россия, Беларусь, Казахстан; валюта на клиента ₽ / Br / ₸ | Интервью | `confirmed` | Первые реальные CSV окажутся только РФ или шире СНГ |
