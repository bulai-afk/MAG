# Discovery MAG — этап 0

Рабочая продуктовая спецификация по интервью с владельцем продукта 9 сентября 2026. Это не подтверждение рыночного спроса.

Ответы владельца помечены как `confirmed` только относительно намерения продукта. Рынок, CSV и готовность платить остаются `to-validate`.
